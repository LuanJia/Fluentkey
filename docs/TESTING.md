## 尚需用户配置后验收

没有使用用户的真实 API Key，也没有向外部模型发送用户输入。真实供应商的可达性、模型质量、额度，以及下列跨应用端到端行为尚未验证，不能视作已完成的兼容性承诺。

| 场景 | 预期 |
|---|---|
| 记事本中输入有错误的英文，按 Alt+F | 仅正文替换；不会按 Enter；原应用支持时可 Ctrl+Z |
| 中文和中英混合的聊天草稿 | 产出自然英文，技术术语和事实不变 |
| 原文是一个问题 | 翻译问题，不回答问题 |
| 网络断开、错误 Key、错误模型 | 状态显示错误，输入框文字不变 |
| 请求期间继续输入／切换窗口／移动鼠标 | 不自动粘贴，结果可在面板复制 |
| 空框、不可复制内容、超长文字 | 不发送模型请求，不误读旧剪贴板 |
| 剪贴板原来是文本、HTML、RTF 或 DIB 图片 | 原剪贴板常见格式恢复；第三方历史记录不保证清除 |
| 不支持备份的特殊剪贴板格式 | 在操作前拒绝，不覆盖原剪贴板 |
| 快捷键被其他程序占用 | 保存失败并保留旧快捷键 |
| 多次触发、取消、处理中退出 | 不并发触发，取消后不执行后续粘贴，退出等待收尾 |
| 管理员窗口、终端、浏览器密码框、富文本 | 按 README 中的兼容边界处理，禁止用敏感数据试验 |

界面状态“已发送替换”表示 SendInput 成功进入输入队列；目标是否消费粘贴仍需实际应用验收。
