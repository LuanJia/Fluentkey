# FluentKey v0.2.0

新增选区中文翻译。默认 **Alt+D**：只复制当前选中的英文，复用现有 OpenAI 兼容 API，在原生桌面悬浮窗显示简体中文，不全选、不替换源内容。可用于聊天记录、网页、文档及输入框中的可复制文本。

- 悬浮窗显示加载、成功或错误状态，支持滚动、拖动、调整大小及一键复制。
- 默认点击窗外自动关闭，可在设置中关闭该行为；窗口内部点击不会自动关闭。
- 关闭加载窗后，后台结果返回不会再次弹窗。最近中文译文可从托盘和设置页重新打开。
- 新增可配置中文翻译快捷键及独立提示词；与英文润色共用 API 配置。两组快捷键检查冲突，支持互换，保存失败会回滚新增注册。
- 保留 Alt+F 原有英文润色与安全回填流程。两种结果分别保存在内存，暂停同时停用两组快捷键。
- 旧配置自动补充新字段：Alt+KeyD、默认中文翻译提示词、窗外关闭默认开启。

验证：15 项自动测试通过；另行执行的两个 Windows 原生交互测试通过，覆盖只读控件部分选区、无选区拒绝、原文不变、原功能回填，以及悬浮窗复制、内部点击、外部关闭、关闭开关和完成后不重弹。API 测试使用本机模拟服务验证两种提示词和中文响应，未消费真实模型额度。

请先从托盘退出旧版再运行新版本。若改变 EXE 位置，请重新启用开机启动。实际聊天客户端、浏览器和模型服务的兼容性需在日常使用中验收；无文本选区或不支持复制的内容不使用 OCR。
