# FluentKey v0.1.2

修复托盘后台快捷键处理及 Electron／Slack 类输入框的自动替换链路。

- 快捷键、托盘和后台完成事件统一走线程安全队列，并独立唤醒原生消息窗口；重入时也会重新唤醒，不再等待设置页绘制。
- 快捷键触发时立即记录目标窗口，避免延迟处理时选错窗口。
- 不再使用包含鼠标移动和合成事件的 GetLastInputInfo 作为回填依据；自身注入按键带标记，鼠标移动不取消任务。键盘输入、点击、滚动和焦点变化仍会阻止自动回填。
- 等待剪贴板序列号变化后再读取，避免轮询读取与目标应用 Ctrl+C 发生争用。
- 回填前重新选中并核对原文，处理编辑器自动收起选区；回填后读回确认。未替换或未确认时显示琥珀色状态，保留 AI 结果供手动复制。
- 配置增加持久写入、有效备份和持续的恢复提示。

验证：12 项自动回归测试通过，另行运行的原生 Windows 交互输入框测试通过；全目标 Clippy 及 Release 构建通过。交互测试覆盖选区收起、鼠标移动、实际替换、只读拒绝、程序化原文变化和取消。未在用户实际 Slack 会话中操作草稿或发送消息，Slack 客户端兼容性仍需用新版试用确认。

使用时请先从托盘退出旧版，再运行新 EXE。保持焦点在 Slack 输入框；请求期间打开 FluentKey 设置会取消自动回填。若移动程序位置，请重新启用开机启动。
