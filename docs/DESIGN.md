# FluentKey 产品与交互设计

## 需求分析

用户的核心任务是“保持当前聊天／工单／邮件的上下文，迅速完成英文表达”，减少复制、切换模型页面、粘贴提示词、复制结果、切回原应用的步骤。首版选择全局快捷键触发，明确操作才发送，避免后台监视输入。

成功路径：写下原文 → Alt+F → 自动选中并复制 → 大模型改写 → 原位粘贴 → 继续工作。原文含中文时翻译，英文时校对并润色；保留事实和技术术语，采用日常美式 IT 工作表达，只输出改写文本，不回答原文中的问题。

### 原提示词的调整

用户给的初始化提示词包含“理解请回复收到”，这是用于聊天初始化的握手。独立 API 请求不能带这个要求，否则可能真的只返回“收到”。默认 system message 保留全部写作要求，移除握手，明确把输入中的问题和指令视作待翻译文本。每次仅发送 system + user 两条消息，互不串联。提示词在设置中可编辑，也可恢复默认。

模型仍可能误改技术含义或受输入指令影响，这不是提示词可完全消除的问题。结果由用户在原应用检查后发送，程序绝不注入 Enter。

## 品牌与视觉

**FluentKey／流畅键**。名称同时表达流利表达和一次按键。品牌图标采用薄荷绿底、深色 F 字形和文本插入光标。原生托盘和窗口使用简化 F 字形以保证 16–32 px 可辨识，SVG 展示版带光标细节。

| Token | 值 | 用途 |
|---|---|---|
| Background | `#0B1016` | 设计稿画布 |
| Surface | `#111820` | 原生设置面板 |
| Accent | `#72E8BE` | 品牌、主操作、就绪 |
| Working | `#78B0FF` | 托盘处理状态 |
| Attention | `#FFBC6E` | 错误托盘状态 |
| Text | 近白色 | 主要内容 |
| Secondary | 灰蓝色 | 辅助说明 |

设置窗口初始 650×780 逻辑像素，允许调整，内容区可滚动。字体使用 Windows 微软雅黑（如存在）配合 egui 默认字体，标题约 25px，正文 14px，辅助说明 12px。采用单页标签结构，避免弹窗层层嵌套。设计稿的圆角、卡片、托盘系统示意是视觉目标，原生控件以实际截图为准。

## 设置结构

1. 顶部品牌与当前状态。
2. 快捷键说明卡：当前已保存快捷键、全选 → 改写 → 原位替换。
3. 三个标签：“连接与快捷键”“写作规则”“最近结果”。
4. 底部持久操作：保存设置、测试连接、取消（处理中）、收起到托盘，以及文字状态。

连接页提供开机启动、Base URL、遮蔽的 Key、显隐开关、模型 ID、快捷键、超时、字符上限和自动替换开关。开机启动放在连接页顶部，默认关闭，说明勾选或取消后点击保存生效，提醒固定程序位置。用户编辑的是草稿，点击保存才生效；测试连接使用草稿。运行中禁止保存或测试，避免请求中途配置变化。

最近结果页只保留一个内存结果，支持编辑、复制、清除。继续输入导致自动回填被阻止时，用户从托盘打开面板即可拿到结果。关闭自动替换可作为人工审核模式，适合谨慎检查译文。

### v0.2.0 选区中文翻译

新增 Alt+D（可配置），独立于 Alt+F 的英文润色：用户在任何支持复制的聊天记录、网页或文档中选中文字；程序只复制选区，复用 API 请求中文译文，不全选或改写源内容。

鼠标附近显示独立置顶工具窗，使用与设置页一致的深色背景和薄荷绿标题；原生只读文本区支持选择与滚动，底部为“复制译文”“关闭”按钮及自动关闭状态提示。窗口可拖动、缩放，定位限制在显示器工作区，显示时不抢焦点。复制按钮在加载与失败时禁用，成功时复制全部译文并显示“已复制”。

默认点击窗外关闭，可在设置里取消；内部点击保留窗口。加载窗被关闭后后台返回不重新弹出，结果仍可从托盘“查看最近中文翻译”及“中文译文”标签重新打开。英文结果与中文译文分别保留内存中的最近一次。

设置页展示两条快捷操作卡，提供两个快捷键、窗外关闭开关及分别可编辑的提示词。默认 Alt+F / Alt+D，禁止相同组合；支持交换两组组合。配置仍需点击“保存设置”才生效。

## 交互状态

| 状态 | 行为与反馈 |
|---|---|
| 首次启动 | 打开设置；Key 和 Model 留空，等待用户配置 |
| 已配置启动 | 设置隐藏，常驻托盘，注册快捷键 |
| 就绪 | 绿色托盘，悬停可查看当前状态 |
| 读取原文 | 等待修饰键释放、备份剪贴板、复制；不激活设置窗口 |
| 调用 API | 蓝色托盘；设置页显示进度秒数；重复快捷键被忽略 |
| 成功 | 没有用户活动则粘贴；绿色托盘；提示可 Ctrl+Z |
| 用户继续操作 | 不自动粘贴，保留结果，托盘提示打开面板复制 |
| 超时／鉴权失败／空结果 | 原文不替换，琥珀色托盘；悬停或面板显示错误 |
| 暂停 | 解除快捷键注册，状态文字显示暂停；可从托盘恢复 |
| 取消 | 标记取消，当前阻塞调用结束后收尾；不执行后续自动粘贴 |
| 关闭设置 | 隐藏窗口，后台继续运行 |
| 托盘退出 | 安全停止后退出；处理中先取消，完成剪贴板收尾 |

## 范围取舍

当前版本没有安装包、自动更新、悬浮窗、逐句翻译、历史记录或浏览器扩展。v0.1.1 加入可选的当前用户登录启动开关。运行时依赖本地原生窗口及全局快捷键，不需要 WebView。保持主路径短，并将“支持任意输入框”的愿望收敛为可验证的常见编辑框兼容性。

下一阶段建议用 Windows UI Automation 校验可编辑／密码状态和目标内容、按应用建立兼容策略、提供选区优先模式及签名安装包。这些尚未实现，不能视作现有能力。
